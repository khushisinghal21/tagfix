How each set was written

    Misses on Held-out 2

      Both failed safe: the customer got a human, not a wrong refund. The fix is the LLM reading layer, which these numbers don't include.

      1. Read the message

        Keyword rules for English, Hinglish and Hindi. Optionally an LLM, whose answer must be one of the known issues or it's ignored.

      2. Look at the account

        If the message is vague but about money, and the passbook shows exactly one problem, use that, and tell the customer it was a guess.

      3. Check the facts

        Plain code decides what's true: duplicates, tariff by vehicle class, return-trip fares, impossible travel between plazas, stuck recharges, blacklist reason.

      4. Act and reply

        Resolve, file a dispute with evidence, ask one question, or hand off. The reply is built from the checked facts, so every amount and ID traces to a transaction.

      Rules it applies

        What's real and what isn't

        • Plaza names and coordinates are real, so the distances are real. Tariffs, accounts and transactions are made up.
        • The LLM layer (reading messages and rewriting replies in the customer's language) is built and unit-tested with a mocked model. It hasn't been run against live traffic, and this page runs without it.
        • An LLM rewrite is thrown away if it drops or changes any amount, time, UPI reference or transaction ID.
        • Everything on this page runs in your browser. Nothing is sent anywhere.
